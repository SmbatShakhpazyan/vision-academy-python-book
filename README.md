# Vision Academy · Python-ի հիմունքներ

Հայերեն ինտերակտիվ ուսումնական գիրք՝ Մարկ Լուցի Learning Python, 6-րդ հրատարակության տրամադրված PDF-ի 1–437-րդ էջերի հասանելի նյութի հիման վրա։

Տեխնիկական տերմիններն անգլերեն են, բացատրությունները՝ հայերեն։
Դասավանդող՝ Սմբատ Շախբազյան։

- Գրքում՝ որոնում և 329 հուշաքարտ։
- PDF տարբերակ՝ 292 էջ։
- Աղբյուրի կտրված կոդերը նշված են, լրացուցիչ օրինակները՝ առանձնացված։
- Կոդային օրինակները, դրանց արտածումներն ու հղումների հասցեները պահպանված են։

`index.html`-ը ինքնուրույն ստատիկ ֆայլ է՝ ներկառուցված տառատեսակներով, նկարներով և PDF-ի ներբեռնմամբ։
